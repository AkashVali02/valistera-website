## Instructions for Claude
Read the HTML page body and embedded JavaScript rather than assuming separate JS/JSON files. Extract the on-screen explanation, question text, all options, correct answer and feedback for each lesson; inspect all 15 final assessment questions and answer keys. Compare WebVTT captions with page content, but **do not claim to have heard the actual video audio unless media playback/transcription is available**. Flag every unsupported regulatory statement, scientific inaccuracy, misleading simplification, ambiguity, wrong answer, missing prerequisite and learner-safety concern. Report each finding with source filename, quoted excerpt, severity and proposed revision. Separate verified facts from tentative concerns; cite current official source links when verified. Do not claim formal GMP approval, certificate validity or regulatory endorsement. Do not publish or modify production.

**Review limitation:** Source text and captions alone cannot establish actual video narration fidelity, visual accuracy or accessible playback. Human reviewers must check those directly.
